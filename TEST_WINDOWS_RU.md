# Проверка клешни EV3

Эта инструкция относится к готовому артефакту Windows, полученному ПОСЛЕ успешной сборки GitHub Actions. Архив исходников сам по себе не содержит EXE.

## Запуск без переустановки основной TRIK Studio

1. Распакуй ВЕСЬ архив `TRIK-EV3-Gripper-Windows-x64` в отдельную папку, например `C:\TRIK-EV3-Test`. Сохрани вложенные папки и DLL.
2. Запусти `Start-EV3-Gripper.cmd`. Он выбирает отдельное имя файла настроек и подготавливает пути к встроенному Python. Устанавливать расширение VS Code или запускать npm не нужно.
3. Выбери комплект **LEGO EV3** и открой 2D-модель.
4. Нажми правой кнопкой по корпусу робота → **«Клешня EV3…»**. Программа должна быть остановлена, иначе пункт недоступен.
5. Включи «Установлена». Выбери свободный моторный порт **A**. При штатных ведущих моторах B и C также свободен D. Порт колеса выбрать нельзя.
6. Оставь начальные размеры и раскрытие. Подтверди. Реалистичная физика включается автоматически.
7. Добавь подвижный мяч или кеглю и помести между открытыми губками перед роботом.

## Тестовая программа обычными блоками EV3

- Мотор **A**, мощность **−40**; ждать **800 мс**; остановить A — закрытие.
- Моторы **B, C** вперёд с мощностью **30**; ждать **1000 мс**; остановить B, C — перенос.
- Мотор **A**, мощность **+40**; ждать **800 мс**; остановить A — открытие и освобождение.

Плюс открывает, минус закрывает. Губки должны коснуться предмета с двух сторон. Предмет, касающийся одной губки, не прикрепляется. Упоры ограничивают раскрытие; при удержании предмета дальнейшее закрытие останавливает энкодер. Не задавай оборот, превышающий полный механический ход, если программа ждёт достижения энкодера: это будет упор, как у физического механизма.

Сохрани модель, закрой и открой её: установка, порт, геометрия и начальное раскрытие должны восстановиться. Удаление удерживаемого предмета не должно приводить к падению программы. Если назначить порт клешни ведущему колесу, клешня отключается, чтобы один мотор не приводил два механизма.

Это первая модель клешни: губки описаны жёсткими контурами, раскрытие связано с ходом мотора. Удержание реализовано соединением Box2D после контакта обеих губок. Деформации деталей и точная модель редуктора не моделируются. Для взаимодействия с предметами оставляй реалистичную физику включённой.
