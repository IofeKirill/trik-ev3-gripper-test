# TRIK Studio: клешни и механизмы EV3

Версия 0.2 переносит управление механизмами в правую панель 2D-модели: выбор картинки, перемещение мышью, поворот синей стрелкой. В панели моторного захвата остаётся максимальное раскрытие. Свободный моторный порт выбирается автоматически; смена — через меню механизма.

Набор: малая, большая, узкая и прямая клешни, моторный захват, четыре длины пиналки. Delete удаляет выделенный механизм. Настройки сохраняются в XML; при старте и возврате в исходное положение раскрытие сбрасывается.

Подвижные части представлены телами Box2D с моторизованными шарнирами, упорами и ограничением усилия. Энкодер следует фактическому перемещению. Удержание возникает после контакта обеих губок с предметом. Пиналка вращается на несколько оборотов. Русская тестовая версия использует отдельные настройки и русский язык элементов Qt.

Локально прошли проверки компиляции изменённых модулей, физические тесты захвата, контактов, упоров, освобождения и сброса, а также XML всех вариантов механизмов. Статус Windows-сборки 0.2 доступен в Actions. Готовый архив после успешного завершения — TRIK-EV3-Mechanisms-Windows-x64.

Сборка 0.1: компиляция и автоматическая проверка запуска Windows прошли успешно. Для 0.2 настроено использование сохранённых результатов компиляции. При следующей сборке дополнительно устанавливаются ресурсы из mechanism-assets/.

Запуск готового архива: распаковать всё в отдельную папку, открыть Start-EV3-Gripper.cmd. Инструкция — TEST_WINDOWS_RU.md.
