# Отдельная Windows-сборка клешни EV3

Это набор для получения готового EXE через GitHub Actions, а не уже собранная программа. Сборка требует GitHub-репозиторий с Actions и доступную квоту Windows-runner.

Загрузи содержимое этой папки в корень отдельного приватного репозитория, сохранив `.github`. Запусти Actions → EV3 gripper portable Windows → Run workflow. После зелёного завершения скачай артефакт TRIK-EV3-Gripper-Windows-x64. Распакуй его целиком и открой Start-EV3-Gripper.cmd. Подробный тест — в TEST_WINDOWS_RU.md.

Workflow не вызывает деплой ТРИКа и не создаёт pull request в их проекте. Пока он не был выполнен успешно, запуск Windows-версии не подтверждён. При подключении GitHub к чату запуск и исправления сборки можно продолжить с ассистентом.
